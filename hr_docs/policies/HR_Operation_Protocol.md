# HR PROTOKOL: Práce se "Slepým vaultem"
# POZOR: Toto je kritický dokument pro compliance.

1. HR nesmí vyžadovat po zaměstnanci jeho Master Key (Kapsli).
2. Pokud zaměstnanec ztratí přístup k vaultu, HR postupuje dle "Protokolu o ztrátě identity" 
   (vyžaduje fyzickou validaci a reissue identity).
3. Veškeré HR záznamy (dovolená, mzda) jsou čitelné pouze v prohlížeči zaměstnance. 
   HR vidí pouze auditní stopu, že "Smlouva byla podepsána".
4. Při auditu OIP (Oblastní inspektorát práce) exportujte "Auditní balíček" z dashboardu. 
   Neukazujte jim databázi, ale vygenerovanou forenzní zprávu.
